2Compreender

Entenda retorno e mutação

Cada método tem um contrato

map() retorna um novo array de mesmo tamanho. filter() retorna um novo array com zero ou mais itens. find() retorna um item ou undefined. reduce() retorna o valor acumulado.

const numeros = [1, 2, 3];
const dobrados = numeros.map(numero => numero * 2);

console.log(numeros);  // [1, 2, 3]
console.log(dobrados); // [2, 4, 6]

Métodos que alteram o array

push(), pop(), splice(), sort() e reverse() podem modificar o array original. Já map(), filter(), slice() e toSorted() retornam novos valores.

Preveja a saída

Antes de executar, diga o resultado e informe se o array original muda: const x = [3, 1, 2]; const y = x.sort();.

3Aplicar

Transforme uma lista de produtos

Exemplo guiado

const produtos = [
  { nome: "Teclado", preco: 120, estoque: 4 },
  { nome: "Mouse", preco: 70, estoque: 0 },
  { nome: "Monitor", preco: 900, estoque: 2 }
];

const disponiveis = produtos
  .filter(produto => produto.estoque > 0)
  .map(produto => ({
    ...produto,
    nome: produto.nome.toUpperCase()
  }));

const total = disponiveis.reduce(
  (soma, produto) => soma + produto.preco,
  0
);

Prática em três etapas

  1. Filtre produtos com preço abaixo de R$ 500.
  2. Crie um array contendo apenas os nomes.
  3. Some o valor dos produtos em estoque.
4Analisar

Escolha o método correto

Perguntas de decisão

  • Precisa de todos transformados? map().
  • Precisa de alguns itens? filter().
  • Precisa do primeiro item? find().
  • Precisa de verdadeiro ou falso? some() ou every().
  • Precisa condensar em um valor? reduce().

Analise o erro lógico

// Objetivo: encontrar um usuário pelo id
const resultado = usuarios.filter(
  usuario => usuario.id === idBuscado
);
console.log(resultado.nome); // undefined

Diagnóstico

Explique o erro e corrija. filter() devolve array; para obter um único usuário, use find() e trate a possibilidade de undefined.

5Avaliar

Compare clareza e eficiência

Duas soluções

// A: duas passagens, intenção clara
const ativos = usuarios.filter(u => u.ativo);
const nomes = ativos.map(u => u.nome);

// B: uma passagem, mais controle
const nomesAtivos = usuarios.reduce((nomes, u) => {
  if (u.ativo) nomes.push(u.nome);
  return nomes;
}, []);

Defenda uma escolha

Qual solução usaria em uma lista pequena de interface? E em milhões de registros? Avalie legibilidade, manutenção e custo de processamento.

Ponto central: a solução mais curta nem sempre é a melhor. A decisão depende do contexto, e a justificativa é parte da competência.

6Criar

Crie uma busca dinâmica

Desafio final: catálogo filtrável

Renderize produtos no DOM e crie uma busca por nome. Normalize o texto com trim() e toLowerCase(), filtre com filter() e gere os cartões com map().

function filtrarProdutos(termo) {
  const busca = termo.trim().toLowerCase();
  return produtos.filter(produto =>
    produto.nome.toLowerCase().includes(busca)
  );
}
  • Exiba mensagem quando não houver resultados.
  • Inclua filtro por faixa de preço.
  • Não altere o array original.
  • Separe busca, renderização e eventos em funções.

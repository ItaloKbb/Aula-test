Estrutura e significado

Ensinando tags HTML

Da identificação das tags à criação de uma página semântica e acessível.

60–90 minutosIniciantePrática individual

Ao final, o estudante será capaz de:

  • reconhecer tags e atributos frequentes;
  • explicar a importância da semântica;
  • construir e avaliar uma estrutura HTML acessível.
Níveis de Bloom1. Lembrar2. Compreender3. Aplicar4. Analisar5. Avaliar6. Criar
1Lembrar

Reconheça as principais tags

Mapa essencial

GrupoTagsFunção
Estruturahtml, head, bodyFormam o documento
Semânticaheader, nav, main, section, article, footerDefinem regiões
Conteúdoh1–h6, p, a, img, ul, liApresentam informações
Formulárioform, label, input, buttonColetam dados

Cartões de memória

Mostre uma tag. O estudante deve dizer sua função e citar um atributo possível. Exemplo: <img> → imagem; atributos src e alt.

2Compreender

Explique estrutura e semântica

Tag não é aparência

HTML comunica o significado do conteúdo. Um <h1> é um título principal, mesmo que CSS faça um parágrafo parecer maior. A semântica beneficia leitores de tela, mecanismos de busca e manutenção.

<!-- Genérico: não explica o conteúdo -->
<div class="menu">...</div>

<!-- Semântico: informa a função -->
<nav aria-label="Menu principal">...</nav>

Explique com suas palavras

Qual é a diferença entre <section> e <div>? Resposta esperada: section agrupa um tema identificável; div é um contêiner sem significado próprio.

3Aplicar

Monte um cartão de artigo

Exemplo guiado

<article>
  <header>
    <h2>Aprendendo HTML semântico</h2>
    <p>Publicado em <time datetime="2026-07-29">29/07/2026</time></p>
  </header>
  <img src="html.jpg" alt="Código HTML em uma tela">
  <p>Semântica torna o conteúdo mais compreensível.</p>
  <a href="/artigo">Ler artigo completo</a>
</article>

Prática

Crie um artigo sobre um hobby. Use título, data, imagem com texto alternativo, dois parágrafos e um link.

4Analisar

Encontre problemas na marcação

Código para investigação

<div class="titulo">Receitas rápidas</div>
<div onclick="abrir()">Ver receita</div>
<img src="bolo.jpg">
<input type="email" placeholder="E-mail">

Diagnóstico

Localize quatro problemas e proponha correções. Pistas: hierarquia de títulos, controle clicável, texto alternativo e rótulo do campo.

Mediação: peça que o estudante justifique cada troca pela função do elemento, não pela aparência.

5Avaliar

Revise como um desenvolvedor

Checklist de revisão

  • Existe somente um título principal claro?
  • A hierarquia de títulos não pula níveis sem motivo?
  • Imagens informativas possuem alt descritivo?
  • Campos estão associados a label?
  • Botões executam ações e links navegam?
  • As regiões principais usam tags semânticas?

Revisão em dupla

Troque o exercício anterior com um colega. Dê uma nota de 0 a 2 para semântica, acessibilidade e clareza, justificando cada nota.

6Criar

Produza uma página autoral

Desafio final: página de evento

Construa a página HTML de um evento com cabeçalho, navegação por âncoras, apresentação, programação em lista, formulário de inscrição e rodapé.

  • Use ao menos oito tags semânticas diferentes.
  • Inclua links, imagem, lista e formulário acessíveis.
  • Valide o documento e explique três escolhas de marcação.

Tutoriais / Trilha 02

Apresentação e layout

Ensinando fundamentos CSS

Da leitura de uma regra à criação de uma interface responsiva e consistente.

90 minutosIniciantePrática guiada

Ao final, o estudante será capaz de:

  • identificar seletores, propriedades e valores;
  • aplicar Box Model, Flexbox e Grid;
  • avaliar e criar estilos responsivos.
Níveis de Bloom1. Lembrar2. Compreender3. Aplicar4. Analisar5. Avaliar6. Criar
1Lembrar

Nomeie as partes de uma regra

/* seletor */
.cartao {
  color: #172033;       /* propriedade: valor */
  padding: 1rem;
  border: 1px solid #ddd;
}

Vocabulário essencial

Seletores: elemento p, classe .card, id #menu, atributo [required] e pseudo-classe :hover.

Unidades: px, %, rem, vw e vh.

Complete a regra

Escreva uma regra que selecione todos os títulos de classe destaque e aplique a cor azul.

2Compreender

Explique cascata e Box Model

Por que “cascata”?

Quando regras competem, o navegador considera importância, especificidade e ordem. Um seletor mais específico normalmente vence; em empate, a última declaração vence.

p { color: gray; }       /* especificidade 0-0-1 */
.aviso { color: orange; } /* 0-1-0: vence */
#erro { color: red; }     /* 1-0-0: vence ambos */

Modelo de caixa

O conteúdo é cercado por padding, border e margin. Com box-sizing: border-box, padding e borda entram na largura declarada.

Preveja

Um elemento tem width: 200px, padding: 20px e borda de 2px. Qual largura final sem e com border-box? Respostas: 244px e 200px.

3Aplicar

Estilize um conjunto de cartões

Exemplo guiado

* { box-sizing: border-box; }

.grade {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

.cartao {
  padding: 1.25rem;
  border: 1px solid #dfe3eb;
  border-radius: 12px;
  background: white;
}

.cartao:hover {
  transform: translateY(-3px);
}

Prática

Aplique tipografia, cores, espaçamento e estado de hover ao cartão criado na aula de HTML. Teste em larguras diferentes.

4Analisar

Compare Flexbox e Grid

CritérioFlexboxGrid
DimensãoLinha ou colunaLinhas e colunas
Uso comumMenu, alinhamento, grupo de botõesGaleria, dashboard, layout de página
ControleConteúdo orienta o fluxoLayout define a estrutura

Escolha e justifique

Para cada cenário — barra de navegação, galeria de fotos e centralização de um modal — escolha Flexbox ou Grid e explique o motivo.

Resposta provável: Flexbox para navegação e modal; Grid para galeria. Aceite outra solução se a justificativa for tecnicamente coerente.

5Avaliar

Audite a qualidade do CSS

  • Os nomes das classes descrevem componentes ou funções?
  • Há repetição que poderia virar uma classe reutilizável?
  • O texto mantém contraste e tamanho legíveis?
  • O layout funciona em 320px e em telas grandes?
  • Estados de foco são visíveis para teclado?
  • !important foi evitado?

Refatoração comentada

Revise o CSS de um colega. Sugira três melhorias e indique o efeito esperado de cada uma.

6Criar

Crie um pequeno design system

Desafio final: landing page responsiva

Defina variáveis para cores, espaçamento e raios. Crie botão, cartão, campo e navegação reutilizáveis. Organize uma landing page com Grid/Flexbox e pelo menos uma media query.

:root {
  --cor-primaria: #6d52d9;
  --espaco: 1rem;
  --raio: .75rem;
}
  • Funciona sem rolagem horizontal.
  • Possui hierarquia visual clara.
  • Componentes compartilham padrões.
